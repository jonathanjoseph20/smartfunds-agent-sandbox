# Governance Contract

This document defines the governance rules for contributing changes to the SmartFunds Agent Sandbox repository.

Legacy tier/evidence governance described below has been retired from active enforcement. Current governance is profile-native, policy-driven, and scope-based. This document remains only as historical reference for older metadata that may still appear on PRs.

For current contributor guidance, use:

- `docs/code-factory-governance.md`
- `docs/runbooks/governance-workflow.md`
- `docs/runbooks/pr-creation.md`

This file should not be used as an implementation contract for current governance behavior.
